# Shine Peerpath

1:1 Career Guidance & Expert Mentorship Marketplace for Shine.com.

## Overview
Shine Peerpath connects job seekers with verified industry professionals and mentors across domains like SaaS Sales, AI/ML, Full-Stack Development, Cybersecurity, and Semiconductor.

## Key Features
- **Trajectory Matching Engine**: Automated CV gap analysis and trajectory recommendations.
- **Expert Video Teasers**: Short introduction videos from verified mentors.
- **1:1 Video Mentorship**: In-browser live sessions with pre-loaded candidate assessment rubrics.
- **Creator Mode**: Expert onboarding wizard with automatic profile pre-fill from Shine CV.
- **Recruiter Talent Search**: Verified peer badges giving candidate visibility boost.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build Production Bundle
```bash
npm run build
```
